# Rebound Hero / 反弹行者

Godot 4.7.2 的 2D 回合弹射 Roguelike 初版。打开 `project.godot`，按 **F5 运行整个项目**，点击“开始新局”。主场景为 `scenes/main.tscn`。

当前可玩内容：5 个模板随机关卡、三种几何障碍物、3 把武器、3 种基础敌人与旋转镜盾 Boss、15 种道具、5 种武器词条、随机商店、品质与强化、掉落、失败重开和通关统计。

| 操作 | 行为 |
| --- | --- |
| 鼠标移动 / 左键 | 瞄准 / 发射 |
| 1、2 / 滚轮 | 切换武器 |
| 按住空格 | 加速弹道结算 |
| Esc | 暂停 / 继续 |
| M | 静音 / 恢复音效 |
| 悬停武器、商品、构筑提示 | 查看详细属性 |

普通靶机不反击；红色射手每个回合会反击一次。金色护盾弧会将弹丸转为敌对弹丸，可能伤害自己。利用侧壁和倾斜镜面击中侧翼与背面。首个商店固定提供路径芯片和霰弹枪，第二个商店提供子母弹枪，让玩家能主动尝试不同打法。

## 内容配置

所有战斗数值、玩家与敌人属性、武器/道具/词条、关卡布局、奖励、商店概率、安全预算及输入绑定均从 `data/` JSON 加载。

| 文件 | 内容 |
| --- | --- |
| `manifest.json` | 内容文件入口、配置版本、结构定义路径 |
| `schema.json` | 配置结构、必填字段、类型、范围与枚举校验 |
| `rules.json` | 战场、模拟、预测、生成验证、商店、奖励、输入、存档位置 |
| `player.json` | 初始生命、金币、站位、武器槽与构筑属性 |
| `weapons.json` | 武器弹丸、伤害、反弹、扇形与分裂参数 |
| `enemies.json` | 敌人属性，以及可组合的护盾/攻击行为 |
| `items.json` | 道具价格、品质、叠加上限与效果列表 |
| `affixes.json` | 武器词条、适用武器与属性路径修改器 |
| `levels.json` | 关卡顺序、敌人、几何布局、扰动与阶段倍率 |
| `visuals.json` | 配色、角色样式、贴图、可替换表现层场景 |
| `audio.json` | 程序音效的频率、时长、音量和音轨预算 |

修改内容后重新运行项目生效。配置加载失败时显示具体文件/字段错误，不使用隐蔽默认值继续游戏。删除内容前同步移除其他文件中的 ID 引用。

扩展方式与运行架构见 [开发与配置说明](docs/开发与配置说明.md)。原始方案见 [游戏设计与实现方案](docs/游戏设计与实现方案.md)。

## 验证

```powershell
& 'D:\Godot4.7.2\Godot_v4.7.2-stable_win64.exe\Godot_v4.7.2-stable_win64_console.exe' --headless --path 'D:\Godot4.7.2\Projects\rebound-hero' --script res://tests/run_tests.gd -- --seeds=200
```

200 个种子 × 5 关，共检查 1000 个布局。还包含镜面/圆形/三角形、护盾、回合状态、子弹预算、分裂寿命、购买事务、词条、存档、实际 UI 信号与输入动作检查，以及通过合法购买完成五关的自动玩家。测试使用中心射线寻找路线，不能替代真人试玩对手感和平衡的判断。

## 当前边界

- 弹丸使用中心射线扫掠；显示的弹丸半径只影响视觉。预览与运行共用同一几何算法。
- 关卡为可配置模板加位置扰动，包含有限角度路线检查与保底模板，不保证数学意义上的完整可解性。
- 首版美术和音效均为可替换的程序表现；尚未制作正式素材、局内继续存档、20 关完整内容和特殊地形。
- 只保存静音设置和局后统计，不继承跨局战力。
